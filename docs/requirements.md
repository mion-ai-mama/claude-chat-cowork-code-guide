# 要件定義書 — Claude Chat・Cowork・Code 在宅ワーク活用ガイド

## 0. アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論）
- 操作者: ブラウザのエンドユーザー（Instagramリール視聴者）
- AI本体(プロンプトY): なし（ページはすべて静的。コンテンツは事前に作成し、静的テキストとして埋め込む）
- MCP: なし
- 自社DB: なし
- フロントUI: あり（このリポジトリそのものがフロントエンド全体）
- 動的変数: なし
- 種別: Web型（静的サイト。バックエンド・DB・ビルド工程なし）
- 配布: マイ専用（発信用GitHubアカウント mion-ai-mama 配下の個人リポジトリ）
- ホスティング: GitHub Pages（無料・静的ファイル配信のみ）

補足: [`instagram-tokuten-template`](https://github.com/mion-ai-mama/instagram-tokuten-template)
を「Use this template」で複製して作成。技術スタック・アーキ構成はテンプレートを踏襲し、
今回はページ内容（`js/content.js` ・ `index.html` ・ 追加CSSコンポーネント）のみを
この特典専用に作り込んだ。

## 1. プロジェクト概要

- 成果目標: Instagramリールの視聴者に配布する特典資料として、Claudeの
  「Chat・Cowork・Code」という3つの使い方の違いと、在宅ワークでの具体的な活用法を
  AI初心者でも理解できるWebガイドとして提供する。
- 目的: 単なる機能解説ではなく、読者に「AIって質問するだけじゃなかったんだ」
  「私の仕事にも使えそう」「これなら1つ試せそう」と感じてもらうこと。

### 成功指標（定量）

- 特典ページ → LINE登録（『AIマネタイズの教科書』）ボタンのクリック率
- リールのプロフィールリンク経由の特典ページ到達率
- ページ平均滞在時間（最後まで読了されるか）
- 「今日やること」チェックリストの完了率（推定・スクロール到達率で代替測定）

### 成功指標（定性）

- 「AIは質問する以外にも使える」と感じてもらえること
- 「これなら私も試せそう」と行動のハードルを下げられること
- 40〜50代AI初心者でも専門用語で離脱しないこと
- Claudeの仕様について事実と異なる記載がないこと（ファクトチェック済み）

## 2. 想定読者（ペルソナ）

- 40〜50代女性、主婦・ママ層
- これから在宅ワークを始めたい、AI初心者
- ChatGPTやClaudeを少し触ったことがある程度。Claude CodeやCoworkはほぼ知らない
- パソコン操作にあまり自信がない、プログラミング経験なし
- 家事・育児・本業などで時間が限られている
- 難しい専門用語を見ると離脱しやすい

## 4. データ設計概要

DBは使用しない。全コンテンツは `js/content.js` の `CONTENT` オブジェクト（JavaScriptの
定数）で一元管理し、`js/script.js` がページ読み込み時にDOMへ反映する。`index.html` には
初期値として同内容を直接記述し、JavaScript無効時のフォールバック表示を担保する。

## 5. セキュリティ要件

- 個人情報の入力フォームなし、認証機能なし、決済機能なし → 該当するセキュリティ対策は最小限
- HTTPS: GitHub Pagesは標準でHTTPS配信
- 外部リンク（LINE誘導ボタン等）は `rel="noopener"` を付与

## 6. 技術スタック

- HTML5 / CSS3 / Vanilla JavaScript（フレームワーク・ビルド工程なし）
- ホスティング: GitHub Pages（`main` ブランチ / root）
- データベース・サーバーサイド処理: 使用しない

## 7. 外部サービス一覧

該当なし（AI本体Yなし）。ページ自体にAIのランタイム処理は含まれない。
